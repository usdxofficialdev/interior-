# Interior Landing Page

This project is a luxury interior design landing page with a 3D look, image-based hero section, and responsive layout.

## Project guide
- Edit [PROJECT_GUIDE.md](PROJECT_GUIDE.md) for the PRD, AI rules, and project memory. It is the single source of truth.
- Website code remains in [index.html](index.html), [styles.css](styles.css), and [script.js](script.js).

## Files
- [index.html](index.html) — page structure and all text content
- [styles.css](styles.css) — design, colors, spacing, and 3D styling
- [script.js](script.js) — hover motion and reveal effects

## Quick start
Open from the project folder:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Easy editing
- Change text in [index.html](index.html)
- Change theme colors in the `:root` block in [styles.css](styles.css)
- Replace the Unsplash images in [styles.css](styles.css) with your own images
- Adjust animations in [script.js](script.js)

## Notes
This page is intentionally built in a clean structure so you can edit it quickly without needing a framework.
